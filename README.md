# Glitch City

A procedural cyberpunk browser game.

## Deployed on GitHub Pages

This project is set up for GitHub Pages. 
The main entry point is `index.html` (formerly `bundled.html`), which contains all game code and logic bundled into a single file for easy deployment.

### How to Deploy

1.  Push this repository to GitHub.
2.  Go to `Settings` -> `Pages`.
3.  Select `main` branch (or `master`) and `/` (root) folder.
4.  Save.

### Development

-   Source code is in `src/`.
-   Tools and scripts are in `tools/`.
-   `dev_index.html` is the development entry point (module-based).
-   `index.html` is the bundled production build.

## Controls

-   **WASD / Arrow Keys**: Move
-   **Space**: Dash
-   **Touch**: Virtual controls appear on mobile devices.
